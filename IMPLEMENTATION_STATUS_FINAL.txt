AUTHENTICATION & SECURITY
================================================================================

Authentication Flow:
1. User enters email/password at /login
2. Frontend POSTs to /admin/login
3. Backend validates and returns JWT token
4. Token stored in localStorage (key: gf_admin_token)
5. Token added to Authorization header for all requests
6. Format: "Authorization: Bearer <token>"
7. On token expiration, 401 response triggers redirect to /login

Token Management:
✅ getToken() - Retrieves from localStorage
✅ setToken() - Stores to localStorage
✅ getAuthHeaders() - Returns headers with token
✅ isAuthenticated() - Checks token existence
✅ logout() - Clears token and redirects

Route Protection:
✅ AuthGuard component on all protected routes
✅ Middleware checks auth status
✅ Redirects to /login if not authenticated
✅ Token validation on each request

FILE UPLOAD INTEGRATION
================================================================================

Banner Image Upload:
1. User selects image at /app-content > Banners
2. Creates FormData with: title + image file
3. POSTs to /admin/banners with Bearer token
4. Backend uploads to AWS S3
5. Returns S3 URL in response
6. S3 URL displayed in banner list

Category Icon Upload:
1. User selects icon at /app-content > Categories
2. Creates FormData with: name + icon file
3. POSTs to /admin/categories with Bearer token
4. Backend uploads to AWS S3
5. Returns S3 URL in response
6. Icon displays next to category name

Logo & Splash Upload:
1. User uploads at /app-content > Branding
2. Creates FormData with: logo + splash files
3. POSTs to /public/logo with Bearer token
4. Backend uploads both to AWS S3
5. Returns S3 URLs for both
6. URLs saved and displayed

S3 Integration Details:
- Bucket: bank-ster-dev (or production bucket)
- Region: ap-south-1
- URL Format: https://bucket.s3.ap-south-1.amazonaws.com/filename
- File validation: type + size
- Error handling: retry on failure
