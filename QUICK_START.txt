================================================================================
TROUBLESHOOTING
================================================================================

Issue: Login fails
→ Verify backend is running at https://gullyfame.com/v1/api/
→ Check credentials
→ Check browser console for error messages

Issue: Images not uploading
→ Verify AWS S3 credentials on backend
→ Check file size limits
→ Verify CORS configuration

Issue: 401 Unauthorized
→ Token expired - log out and log in again
→ Check localStorage for gf_admin_token
→ Try clearing cache

Issue: Pages not loading
→ Clear browser cache
→ Restart dev server
→ Check API base URL is correct
